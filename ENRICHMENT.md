# Humanities Enrichment & Flashcard Generation

This directory contains tools to enrich humanities exam content (English, Global History, US History) with educational explanations and generate flashcard decks.

## Quick Start

**Prerequisites:**
- `ANTHROPIC_API_KEY` environment variable set with a valid Claude API key
- Node.js 18+ with `@anthropic-ai/sdk` installed

**Run Full Enrichment (questions + flashcards):**
```bash
ANTHROPIC_API_KEY=sk-... node scripts/enrich-full.mjs
```

**Questions Only:**
```bash
ANTHROPIC_API_KEY=sk-... node scripts/enrich-full.mjs --questions-only
```

**Flashcards Only:**
```bash
ANTHROPIC_API_KEY=sk-... node scripts/enrich-full.mjs --flashcards-only
```

## Scripts

### `scripts/enrich-full.mjs`
**Complete enrichment pipeline.**
- Enriches all MC questions in humanities exams with `explanation` + `diveDeep` fields
- Generates ~45–50 flashcard terms per subject
- Applies changes to all three platforms: `mobile/src/content`, `shared/content`, `src/data`
- Non-destructive: only fills missing fields, preserves existing content
- Reports total enriched questions and flashcards by subject

**Output:**
```
📝 Enriching Questions...
  english: +342 questions enriched
  global-history: +156 questions enriched
  us-history: +85 questions enriched

📚 Generating Flashcards...
  english: +40 flashcards added
  global-history: +50 flashcards added
  us-history: +45 flashcards added

✅ Complete!
```

### `scripts/enrich-humanities.mjs`
**Questions only (simpler, lighter).**
- Enriches MC questions for the three humanities subjects
- Skips flashcard generation
- Useful for iterative improvements or testing

### `scripts/generate-humanities-exams.mjs`
**Raw wire-up (one-time use).**
- Converts `output/data/<subject>/<session>.json` (extracted OCR) → app exam modules
- Already ran; can re-run to refresh all exams from source
- Outputs: 55 exam modules (English 31, Global 15, US 9) across all platforms
- Generates index snippets for manual splicing into registries

## What Gets Enriched

### Questions
Each multiple-choice question receives:
- **`explanation`** (1–2 sentences): Directly answers the question, explains why the correct choice is right
- **`diveDeep`** (4–5 sentences): Deeper context, why wrong choices fail, common misconceptions, test-taking strategies

### Flashcards
~130–140 flashcard terms across humanities:
- **English:** Literary devices, grammar/mechanics, reading comprehension, rhetoric
- **Global History:** Empires/civilizations, geographic terms, political systems, historical events
- **US History:** Constitutional concepts, historical periods, movements, key documents

Each flashcard:
```javascript
{ 
  id: 'en1',
  term: 'Metaphor',
  definition: 'Figurative comparison between two unlike things without using "like" or "as"; creates vivid imagery.',
  topic: 'english-literature'
}
```

## Platforms & Sync

Changes are written to all three platforms simultaneously to keep them in sync:
1. **`mobile/src/content/regents-exams/`** — Mobile app (Expo)
2. **`shared/content/regents-exams/`** — Deployed web app (chromebook)
3. **`src/data/regents-exams/`** — Root Vite app (undeployed, for branch `feat/web-app-vite`)

After running enrichment:
- Verify builds pass: `npm run build` (root), `cd chromebook && npm run build`
- Commit changes to git
- Deploy: `./scripts/deploy.sh --images-only` (web), `cd mobile && npx eas build -p ios --auto-submit` (mobile)

## Troubleshooting

**API Key Error:**
```
Could not resolve authentication method
```
Ensure `ANTHROPIC_API_KEY` is exported before running:
```bash
export ANTHROPIC_API_KEY=sk-...
node scripts/enrich-full.mjs
```

**Module Import Error:**
```
Cannot find module 'file://...'
```
Exams must already exist (they're generated by `generate-humanities-exams.mjs`). Run that first if they're missing.

**Flashcard Merge Error:**
Ensure `flashcards.js` exists in all three platforms. If missing, create a minimal stub:
```javascript
export const flashcards = []
```

## Notes

- **Quality:** Enrichment uses Claude Opus 4.8 (highest accuracy). Each question takes ~15–20 seconds; full enrichment of 583 questions takes ~2–3 hours.
- **Cost:** ~$0.20–$0.30 for full enrichment (questions + flashcards). Check Anthropic pricing.
- **Idempotent:** Safe to re-run; already-enriched questions are skipped.
- **Manual Review:** After enrichment, spot-check a few questions per subject for quality before deploying.
