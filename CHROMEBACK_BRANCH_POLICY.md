# Chromebook Branch Policy

**Branch:** `feat/chromebook`

- The Chromebook version of the application lives exclusively on the `feat/chromebook` branch.
- **Do NOT merge** this branch into `main` under any circumstances.
- All future development, bug fixes, and enhancements for the Chromebook version should remain on this branch.
- If changes need to be reflected in the main web app, they must be implemented separately in the appropriate branches.

This file serves as a permanent reminder for the team to keep the Chromebook code isolated from the main production line.
