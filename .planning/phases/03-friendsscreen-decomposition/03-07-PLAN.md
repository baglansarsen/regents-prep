<objective>
Split the leaderboard container's first two pieces into named widgets: the three-way mode segment, and the whole friends-mode body that composes the podium and the rank-row list.

**As a** student comparing myself with my friends, **I want to** switch segments and watch the podium reveal exactly as before, **so that** the leaderboard container being broken into widgets is invisible to me.

Purpose: `LeaderboardTab` is the largest container this phase produces, and it needs two passes to split — the same shape Phase 2's setup branch needed. This is pass one: the segment control and the friends body. Plan 03-08 takes the school and league bodies in the following wave, because both passes edit the same container file.

Output: `LeaderboardModeToggle.jsx`, `FriendsLeaderboard.jsx`, two tests, and a slimmer `LeaderboardTab`.
</objective>
