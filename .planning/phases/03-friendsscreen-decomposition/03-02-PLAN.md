<objective>
Move the three components that already exist as module-local functions inside `mobile/src/screens/FriendsScreen.jsx` — the initial-letter avatar, the animated top-three podium, and the animated rank row — into their own files under `mobile/src/components/FriendsScreen/`, body for body, with the medal table relocated alongside them as a shared data module. Each gets a test at the tier its interactivity assigns it.

**As a** user of the leaderboard, **I want to** see the podium reveal, the rank rows slide in, and tapping any of them open that person's profile exactly as before, **so that** the file reorganisation underneath is invisible to me.

Purpose: these three are the highest animation-risk units in the screen and the ones every leaderboard mode depends on. Relocating them before any tab container is extracted means the container plans that follow can simply import them, and no later plan has to touch the screen file for this reason.

Output: `medals.js`, `Avatar.jsx`, `Podium.jsx`, `RankRow.jsx`, three test files, and a screen that imports rather than declares them.
</objective>
