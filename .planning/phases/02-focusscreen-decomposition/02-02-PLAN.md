<objective>
Move FocusScreen's active-session branch — the full-bleed scene background, session header, pet area, cycle dots, timer ring, transport controls, and task list — out of the screen and into `FocusActiveScreen`, plus relocate the large-pet component it renders into its own file. Both are driven by the orchestration hook's return value and covered by interaction tests.

**As a** student in the middle of a focus session, **I want to** the running-session screen to behave exactly as it did before, **so that** a refactor I never asked for never costs me a pomodoro.

Purpose: the active branch is the second of three render branches and the one with the most interactive surface. Getting it out of the screen is what makes plan 02-04's final reduction of `FocusScreen.jsx` a small, reviewable diff instead of a rewrite.

Output: `FocusActiveScreen.jsx`, `BigPetDisplay.jsx`, two test files, and a shorter `FocusScreen.jsx`.

This expands out from plan 02-01's proven slice: same hook contract, same component shape, same test shape — applied to a second branch. Plan 02-05 then splits this container's inner widgets out; this plan does the branch-level move only.
</objective>
